# 30-Day Launch Plan

## Week 1: Foundation

- Pin the GitHub repo and release.
- Add a short demo GIF or screenshots with synthetic data only.
- Open 5-8 good first issues.
- Open issues for known limitations instead of hiding them.
- Add a clear project board or roadmap.
- Post the launch on personal LinkedIn/X/Mastodon.

## Week 2: Self-Hosting Communities

Post carefully, not as spam:

- r/selfhosted
- r/homelab
- r/proxmox
- relevant Asterisk or VoIP communities
- Home Assistant community forum, only if framed as future integration

Ask for feedback on:

- install experience
- STT providers
- Proxmox LXC design
- dashboard needs

## Week 3: Builder Communities

- Hacker News `Show HN`
- GitHub Discussions welcome thread
- Discord/Telegram maker groups where allowed
- n8n community forum for automation angle

## Week 4: Proof and Trust

- Publish STT benchmark notes.
- Publish architecture roadmap.
- Publish a short video: install, dashboard, simulated call.
- Write a blog post: `Why self-hosted AI communication matters`.
- Invite contributors for STT, Asterisk and dashboard work.

## Success Metrics

- 50 GitHub stars
- 5 meaningful issues from external users
- 1 external contributor
- 1 successful external install attempt
- 1 tested Proxmox LXC install outside the original environment
