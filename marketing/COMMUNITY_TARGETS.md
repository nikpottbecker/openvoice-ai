# Community Targets

## Best-Fit Communities

- GitHub self-hosted lists
- r/selfhosted
- r/homelab
- r/proxmox
- r/VOIP
- Home Assistant Community
- n8n Community
- Asterisk Community
- Hacker News
- Product Hunt, later when the setup wizard is smoother

## Outreach Rules

- Do not post the same message everywhere.
- Lead with the problem, not hype.
- State preview / early alpha clearly.
- Ask for feedback, not only stars.
- Share architecture and limitations honestly.
- Never publish private call data.

## Good First Issues To Create

- Improve README install clarity.
- Add screenshots with synthetic data.
- Add one-click demo mode with fake calls.
- Add STT provider interface.
- Add setup wizard skeleton.
- Add dashboard health page.
- Add Docker Compose demo profile.
- Add Proxmox LXC install validation checklist.

## Contributor Hooks

- STT experts: help with German telephone audio.
- Asterisk users: review SIP and dialplan examples.
- Frontend developers: improve dashboard UX.
- Self-hosters: test install paths.
- Security-minded contributors: review secrets and access model.
