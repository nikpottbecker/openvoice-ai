# Code of Conduct

OpenVoice AI follows the Contributor Covenant principles.

Be respectful, constructive and privacy-conscious. This project touches communication data, so contributors must treat user recordings, transcripts, phone numbers and credentials as sensitive at all times.

Unacceptable behavior includes harassment, doxxing, publishing private data, or submitting code that intentionally weakens authentication or data protection.

Report concerns through the channels listed in `SECURITY.md` or `SUPPORT.md`.
