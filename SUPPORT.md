# Support

For help:

- read `README.md`
- check `docs/`
- search existing issues
- open a bug report with sanitized logs

When asking for help, remove:

- API keys
- phone numbers
- email passwords
- SIP credentials
- Cloudflare tokens
- recordings and transcripts from real callers

For security-sensitive reports, use `SECURITY.md` instead of a public issue.
