# Monetization Strategy

OpenVoice AI should be monetized without weakening the open-source project.

## Principle

The core self-hosted platform should remain useful under the MIT license.

Revenue should come from convenience, support, managed infrastructure, enterprise controls and professional services, not from locking essential self-hosting features behind a paywall.

## What Should Stay Free

- Core phone-agent runtime
- Local STT/TTS support
- Basic dashboard
- Asterisk/SIP examples
- Email draft workflow
- Provider configuration
- Docker Compose / Debian / Proxmox install docs
- Plugin SDK basics
- Personal and small-team self-hosting

## Revenue Streams

### 1. Managed Cloud

Hosted OpenVoice AI for users who do not want to manage servers.

Potential pricing:

- Starter: 19-29 EUR/month
- Team: 59-99 EUR/month
- Business: 199+ EUR/month

Good for:

- freelancers
- agencies
- small businesses
- non-technical teams

### 2. Pro Support

Paid help for self-hosted users.

Potential pricing:

- one-time setup call: 99-249 EUR
- monthly support: 49-199 EUR/month
- priority support: custom

Good for:

- Proxmox users
- Asterisk/SIP users
- local AI users
- small businesses

### 3. Enterprise Edition

Paid features for companies.

Possible enterprise-only features:

- SSO / OIDC / SAML
- LDAP / Active Directory
- advanced RBAC
- audit logs
- retention policies
- multi-tenant admin
- HA / clustering
- compliance exports
- team management
- advanced backup/restore

### 4. Marketplace Revenue

Plugin marketplace with optional paid plugins.

Examples:

- premium CRM connectors
- advanced WhatsApp provider
- advanced analytics
- vertical workflows for agencies, photographers, clinics, trades, real estate

Revenue model:

- 70/30 marketplace split
- verified plugin badge
- hosted plugin registry

### 5. Professional Services

Implementation services:

- phone system migration
- Asterisk/FreePBX integration
- custom prompts and workflows
- n8n automations
- dashboard customization
- local AI optimization

### 6. Hardware / Appliance

Preconfigured Mini-PC or VM image.

Offer:

- OpenVoice AI Box
- preinstalled Proxmox/LXC image
- tested microphones/phone adapters
- optional support plan

### 7. Sponsorship

GitHub Sponsors, Open Collective or Polar.

Good for:

- early believers
- self-hosting community
- companies using the project internally

## Recommended First Monetization Path

Start with services, not SaaS.

1. Make the open-source project credible.
2. Offer paid setup/support for early adopters.
3. Use real support requests to learn what businesses need.
4. Build managed hosting only after the setup flow is stable.
5. Add enterprise controls once there are real team users.

## Avoid

- fake stars
- paid reviews without disclosure
- spamming communities
- hiding basic self-hosting behind a paywall
- collecting private call data by default
- promising production readiness before STT and setup are stable
